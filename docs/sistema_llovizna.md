**4 Descripción técnica de la propuesta.**

**Principio de la Propuesta:**

La implementación del Sistema Llovizna, consiste en la unión de muchas tecnologías; combinadas de tal manera que permitan una interacción entre el Estudiante, el Profesor, y el Computador Grupal (CG).

El CG estará compuesto por una unidad central de procesos (CPU) y varios periféricos de entrada y salida. Tendrá un sistema operativo capaz de manejar las múltiples señales provenientes de los estudiantes, procesar los datos y mostrar el resultado de la votación realizada.

De esta forma, al entrar en la clase el profesor comenzará a explicar contenido y al cabo de cierto tiempo (15-25 min) el profesor con ayuda del sistema llovizna realizará un examen rápido o quizz en el cual se dará una pregunta y 4 posibles respuestas. El sistema arrojará los resultados que la audiencia emitió. Luego de repetir el proceso con algunas otras preguntas, el profesor y el estudiante conocerán cual contenido es necesario aclarar, fortalecer, ejemplificar o ampliar.

El profesor podrá mejorar la explicación utilizando recursos tomados de la base de datos del sistema, o podrá agregar su explicación como aporte a la base de datos y el sistema, de manera que otra aula lo pueda utilizar.

**Detalles de diseño:**

Se presenta el diseño de una posible implementación. Existen dos directrices principales en cuanto al diseño del sistema llovizna se refiere, por un lado está el hardware, y por el otro está el software; ambos trabajando juntos conforman el sistema.

El **Hardware** necesario para constituir el sistema llovizna, consta de:

**Unidad central de procesos. (CPU)**

Se emplea una tarjeta madre, con procesador dual-core y sistema operativo Linux.

**Periféricos de Salida**

**Video proyector**: Se utiliza para mostrar datos a la audiencia.

**Cornetas:** Se utiliza para producir música, o señales a todo el aula.

**Periféricos de Entrada**

**Dispositivo de Interacción Mejorado (DIMe);** Dispositivo electrónico que se encontrará en el pupitre y que permitirá seleccionar a cada estudiante una (1) de cuatro (4) opciones para responder a una pregunta.

**Cámaras:** Permitirá hacer grabaciones en determinados momentos para guardar contenido.

**Microfono:** Permitirá medir niveles de ruido y grabar audio.

**Teclado:** Permitirá introducir texto al sistema

**Tiza-ratón:** Permitirá interactuar con el sistema a través del pizarrón, como si fuera un ratón sobre la pantalla, pero en forma de tiza o marcador.

Y el conexionado y la distribución de estos elementos dentro del aula.

Con respecto al **Software** del sistema se tiene que manejar tres niveles: software de los periféricos, sistema operativo y plataforma web.

**Software de periféricos:**

El sistema cuenta con una pizarra interactiva, que permitirá al profesor interactuar con el pizarrón como si fuera una pantalla táctil, para realizar esta labor, se dispondrá de un software que identificará y codificará las señales provenientes del “tiza-raton”.

Además cuenta con dispositivos en los pupitres que permiten realizar la votación de los estudiantes, esta votación llegará a la CPU y debe ser manejada y organizada. Un software se debe encargar de esta labor, se realizará en lenguaje de programación “Python”.

**Sistema Operativo:**

El sistema operativo a utilizar será un sistema Linux, podría ser la distribución Canaima. Los sistemas Linux permiten integración completa con los periféricos mencionados, además de ofrecer posibilidades de manipulación.

**Plataforma web:**

El sistema dispondrá de una página web y una base de datos en línea que contendrá un conjunto de preguntas para su uso en los diferentes contenidos, también dispondrá de recursos audiovisuales para apoyar los contenidos ofrecidos. Sin embargo de tener aulas que no tengan acceso a internet se trabajaría con un servidor local.
